- **Trusted** = `answer.trustState` certified or governed. **Wrong** = `executionMatched` false (answerable) or `passed` false (unanswerable: answered instead of stopping).
- **Per answer** the script extracts the route (engine route, tiers, semantic engine and governed metric names from the run's compilation receipt), the structured reading (`askIntentV1`: measures, group-by, `unresolved` clauses), the host's coverage warnings, DQL's SQL and the rows DQL showed (artifact in a copy of `agent-runs.sqlite`, matched on identical SQL, all attempts of the cell), and the gold SQL and rows.
- **Root cause** is a hand-written judgement per distinct (question, root cause), in the `JUDGEMENT` dict of the script; the script refuses to run if a wrong trusted answer is not covered. Facts the evidence cites are re-checked by read-only SQL on a copy of the L0 warehouse (`EVIDENCE_SQL`, results in `taxonomy.json`).
- **Lenient grade** reuses the paper's grader: the "re-grade (rows)" section of `paper/stats_v2/stats_v2.py` is executed verbatim (sha256 `8b483aefb1e1…`). DQL rows come from the run store; P and A rows from re-running the recorded SQL on a copy of the L0 warehouse.
